\section{D5 \quad $\alpha$粒子的能量损失 \quad\heiti 预习报告}
	
\subsection{实验目的}
\begin{enumerate}
	\item 了解核辐射安全以及防护
	\item 了解金硅面 $\alpha$ 谱仪的工作原理及其特性；
	\item 通过测量分析两种 $\alpha$ 放射源 $^{241}\mathrm{Am}$ 和 $^{239}\mathrm{Pu}$ 的能谱形状（如：作能量刻度、求能峰和能量分辨率），掌握基本的 $\alpha$ 射线能谱的测量方法和能量刻度定标方法；
	\item 通过利用 $\alpha$ 粒子测量箔膜的厚度；了解天然射性 $\alpha$ 粒子与物质的相互作用过程；
	\item 通过观察和数据处理，理解随机性在微观世界的普遍存在，以及统计方法的实验意义。
	
\end{enumerate}
