\subsection{原理概述}

	CCD（Charged Coupled Device）起源于爱因斯坦的光电效应理论，是一种能够将光学信号转换为电信号的电荷耦合器件。

	CCD 主要有线阵列和面阵列两种基本类型，各有不同的工作原理与特性。
	\begin{itemize}
		\item 线阵 CCD 通常用于自动化生产过程或生产线上用作在线非接触光电检测设备，主要检测物体的尺寸、运动速度、加速度、运动规律、位置、面形、粗糙度、变形量、光学特性变化、条码信息和其他应用。
		\item 面阵 CCD 的优点是可以获取二维图像信息，广泛应用于面积、形状、尺寸、位置、甚至温度等的测量。
	\end{itemize}

	CCD 主要由感光部分（光敏单元）、转移存储（移位寄存器）和移位输出控制等部分组成。光敏单元由光电二极管或MOS/CMOS阵列构成，能够存储电荷，当光线照射时产生电子-空穴对并存储在单元中。存储的电荷在积分时间后转移到MOS结构的移位寄存器，该寄存器通过时钟脉冲信号控制电荷的定向转移。最终，信号电荷被输出到放大器，经过放大、滤波和模数转换后得到图像数据。

	实验中使用东芝 TCD1208AP \textbf{二相线阵} CCD 芯片 和 索尼 ICX409AK \textbf{面阵} CCD 芯片。
	\begin{itemize}
		\item \textbf{二相线阵 CCD 芯片：}

			其工作时主要由四路时序脉冲控制：SH，Φ1，Φ2 和 RS。其中 SH 是转移栅脉冲，Φ1，Φ2 是模拟转移寄存器驱动脉冲，RS 是复位脉冲。当 SH 高电平来到时，Φ1 为高电平，Φ2 为低电平（Φ1，Φ2 相互为互补时序脉冲）。

		\item \textbf{面阵 CCD 芯片：}

			在场消隐期间，V1~V4 及 H1、H2 上所加的脉冲均属于均衡脉冲，V1、V2 为正脉冲，使光积分电极完成光积分。在场消隐期间，V1 和 V3 的正脉冲完成信号由光积分区向垂直移位寄存器转移。
	\end{itemize}



	\textbf{驱动脉冲与积分时间关系：}

		
		CCD的输出信号由\textbf{驱动频率}和\textbf{积分时间}共同决定。驱动频率影响信号频率，积分时间影响帧速率。电荷转移时间限制了驱动脉冲频率的上限，若驱动频率过高导致电荷转移跟不上，转移效率会下降。积分时间是光敏单元感光时间，决定了信号电荷的感光和传输完成。



	\vspace{5mm}
	\textbf{投影成像测量法与角位置测量法：}

		
		投影成像测量法适用于测量与CCD传感面尺寸相当的物体尺寸，通过计算CCD上阴影宽度来获得被测物体尺寸，测量精度受平行光准直性和CCD像元尺寸影响，需要算法修正和尺寸标定以提高准确性。

		角位置测量法利用CCD传感器进行非接触式测量，通过光学换算将CCD像素尺寸转换为反射镜旋转角位置，实现高精度、高可靠性的静态和动态小角度测量。测角系统工作原理涉及反射镜转动量转换为激光光束角度变化，CCD完成光电转换并输出与光电荷量成正比的电压信号，经过滤波、放大处理后，通过A/D转换和USB接口传输至计算机，上位机软件计算出转动角度量，实现角位置测量功能。
	


	\textbf{图像处理方法：}

		\begin{itemize}
			\item \textbf{二值化：}
			
				二值化处理是将图像和背景分离成二值（0,1）的方法，适用于不要求图像灰度的系统，以提高处理速度和降低成本。
				通过光学系统将被测物体成像在CCD光敏像元上，利用CCD视频信号中图像尺寸边界处的电平变化，通过二值化处理将图像尺寸部分与背景部分分离成二值电平。

				% 二值化处理方法包括固定阈值法、浮动阈值法和微分法等，其中固定阈值法通过硬件实现，通过电压比较器将CCD视频信号与可调电平阈值进行比较，输出二值化方波信号。

				% 调节阈值电压可以改变方波脉冲的宽度，从而获得方波脉冲宽度与被测物体直径的精确关系。
			\item \textbf{点运算：}
			
				点运算是数字图像处理中的基础技术，它通过灰度变换函数（GST）对输入图像的每个像素点进行处理，以生成输出图像。这种处理包括灰度的线性变换，可以调整图像的对比度和亮度；灰度的阈值变换，用于将图像转换为黑白二值图像；灰度的窗口变换，保持特定灰度范围内的值不变，而将范围外的值设置为0或255；灰度拉伸变换，通过设定转折点实现分段线性变换；以及灰度均衡变换，通过调整使图像的灰度分布更加均匀，提高图像的整体对比度。
		\end{itemize}
	




\subsection{实验前思考题}

% 思考题1
\begin{question}
	MOS 电容器工作原理是什么？
\end{question}

	MOS电容器的工作原理基于金属-氧化物-半导体结构，其中金属栅极和半导体衬底通过中间的氧化物绝缘层隔开，通过在栅极施加电压来控制半导体表面的电荷分布，形成不同的工作模式，包括堆积、耗尽和反型，从而实现电荷的存储和转移。

	





% 思考题2
\begin{question}
	光电转换的物理原理是什么？
\end{question}

	光电转换的物理原理基于光电效应，即当光子与物质相互作用时，如果光子的能量大于物质中电子的束缚能，光子可以被物质吸收，导致电子从物质中释放出来，从而将光能转换为电能，这一过程在光电探测器、太阳能电池等设备中得到应用。



	




% 思考题3
\begin{question}
	CCD 驱动脉冲是如何实现信号电荷转移和输运的？
\end{question}

	CCD驱动脉冲实现信号电荷转移和输运的过程涉及时钟脉冲对CCD各电极的控制。在CCD中，电极被分为几组，称为相，每组电极施加相同的时钟驱动脉冲。这些驱动脉冲按一定规律变化，使得电极下的电荷包沿半导体表面按一定方向移动。CCD正常工作所需的相数由其内部结构决定，例如三相CCD需要三相时钟脉冲来实现电荷的逐单元转移。电荷转移时，通过改变相邻电极上的电压，形成势阱和势垒，使得电荷从一个电极转移到另一个电极。当电压设置使得相邻电极的势阱深度相同时，电荷会在两个电极下均匀分布，随后通过调整电压使电荷完全转移到下一个电极，实现电荷的有序转移。这种电荷耦合的过程使得CCD能够将光敏单元收集的信号电荷按特定顺序输出，完成信号电荷的转移和输运。








% 思考题4
\begin{question}
	请解释转移脉冲 SH 在线阵 CCD 中的作用？
\end{question}

	转移脉冲SH在线阵CCD中的作用是沟通或阻隔光敏单元（PD）和电荷耦合器件（CCD）之间的电荷转移，并控制光积分时间。当SH脉冲为高电平时，它使得光敏单元和垂直寄存器之间的势阱沟通，允许光敏单元中的信号电荷转移到垂直寄存器中。当SH脉冲由高变低时，它形成的浅势阱将光敏单元和垂直寄存器下的势阱隔离开，从而结束电荷的转移过程。这样，存储栅的势阱进入光积分状态，而模拟移位寄存器将在其他驱动脉冲的作用下驱动信号电荷向左转移，最后信号经由输出端输出。简而言之，SH脉冲是控制电荷从一个区域转移到另一个区域的关键信号，对于CCD中信号电荷的采集和转移至关重要。










% 思考题5
\begin{question}
	解释为什么修改驱动频率和积分时间会导致线阵 CCD 相机输出信号产生影响？
\end{question}

	修改驱动频率和积分时间会导致线阵CCD相机输出信号产生影响，原因在于这两个参数直接影响了CCD的电荷转移和光积分过程。驱动频率决定了CCD中电荷转移的速率，即电荷从一个像素转移到下一个像素的速度。当驱动频率改变时，电荷转移的周期也会随之变化，这会影响到每个像素的积分时间，即电荷在像素中积累的时间。积分时间是决定CCD感光时间的关键参数，它决定了光子在像素上积累电荷的时间长度。积分时间的增加会导致更多的光子被收集，从而增加输出信号的幅度；相反，积分时间的减少会导致较少的光子被收集，从而减少输出信号的幅度。因此，调整驱动频率和积分时间可以改变CCD的曝光特性和输出信号的强弱，这对于图像的亮度、对比度和噪声水平都有重要影响。











% 思考题6
\begin{question}
	如果输入到线阵 CCD 光敏面上的光太强或积分时间太长，使 CCD 器件工作在饱和状态，此时线阵 CCD 输出信号有何特点？
\end{question}

	当输入到线阵CCD光敏面上的光太强或积分时间太长，导致CCD器件工作在饱和状态时，线阵CCD输出信号的幅度会达到其最大值，即饱和输出电压。这是因为CCD的光敏单元在积分时间内积累的电荷量超过了其能够存储的最大电荷量，导致无法再增加输出信号的幅度，输出信号的波形会失真，表现为信号电荷混杂，无法区分。在这种情况下，CCD的动态范围被超出，无法准确反映被测物体的光强分布，因此，为了避免信号失真，应适当调整光照强度或积分时间，确保CCD工作在非饱和状态。











% 思考题7
\begin{question}
	相机与反射镜距离的变化会有什么样的影响？
\end{question}

	我们在软件中可以测量的是移动的像素个数，即弧长；相机与反射镜的距离即半径，二者相除即可得到弧度；

	原则上，半径越长，弧度越小，小角近似误差越小。













% 思考题8

	如果被测物体尺寸宽度太大，超过了线阵 CCD 相机测量范围，有什么方法可以改善实验中的光路呢？

% 思考题9
\begin{question}
	如果图像为全黑或全白，则对应的灰度值应该是多少？
\end{question}

	对于一个全黑的图像，其对应的灰度值是0；而对于一个全白的图像，其对应的灰度值应该是255（在8位图像中）。在8位灰度图像中，灰度值的范围是从0到255，其中0代表黑色，255代表白色，中间的值代表不同级别的灰色。














% 思考题10
\begin{question}
	为什么直方图均衡化能有效增强图像?
\end{question}

	它通过调整图像的灰度分布，使得像素值在整个灰度范围内更加均匀地分布。这种方法扩大了图像的动态范围，增强了图像的整体对比度，使得图像中的细节更加清晰可见。具体来说，直方图均衡化对图像中占比大的灰度级进行展宽，而对占比小的灰度级进行压缩，从而增大了图像的对比度。此外，直方图均衡化通过非线性拉伸，重新分配图像像素值，使得原本集中的像素值分布到所有可取值的范围，这样图像就既有明亮也有灰暗的部分，对比度和亮度得到了改善。因此，在人眼视觉里，经过直方图均衡化的图像会比没有经过处理的图像更加清晰。简而言之，直方图均衡化通过使图像的直方图分布更加均匀，有效地增强了图像的视觉效果和对比度。













% 思考题11
\begin{question}
	白色的图片在各个不同的通道灰度值有什么特点？
\end{question}

	由于白色包含所有的像素成分，所以对于一张白色的图片，在RGB色彩模式下的三个通道（红、绿、蓝）中，每个通道的灰度值都会非常高，接近于最大值255。
















% 思考题12
\begin{question}
	如果被测物体较厚，还能用上述光路测量么？
\end{question}

	\begin{itemize}
		\item 面阵CCD相机在二维平面上捕捉被测物体的投影，对于厚度的测量并不直接。如果物体较厚，其在成像过程中可能会产生阴影或遮挡效应，这会导致测量平面尺寸时出现误差。

		\item 较厚的物体在成像时可能会引起衍射现象，这会导致图像边缘变得模糊，影响细节的清晰度。这种模糊可能会降低测量的准确性，尤其是在需要精确测量边缘或表面特征时。
	\end{itemize}

\section{D7 \quad CCD 原理与应用 \quad\heiti 分析与讨论}

\subsection{实验数据分析}


	\subsubsection{线阵 CCD 驱动及其特性测量}
		
		\begin{enumerate}
			\item 由\cref{tbl:线阵CCD的测试端子 SH、RS、Φ1、Φ2 周期和频率记录}，可以看到 SH 端子频率为0.145kHz，RS端子频率为719kHz，Φ1与Φ2端子的频率为360kHz。
				\begin{itemize}
					\item SH 是转移栅脉冲，负责控制电荷的转移。
					\item RS 是复位输出级的复位脉冲，用于重置像素点，使其准备接收新的光信号。
					\item Φ1，Φ2 是模拟转移寄存器驱动脉冲。
					\item Φ1 和 Φ2 的频率（360 kHz）与 RS 信号的频率（719 kHz）之间约为 1:2 的关系。这种关系保证了复位与电荷转移的配合。
					\item RS信号频率远高于SH信号，确保了像素点的电荷清零，从而防止上一帧的电荷残留影响当前帧的数据。
				\end{itemize}
			\item 由\cref{fig:Phi1-Phi2}可以看到，Φ1和Φ2路的信号之间频率相同，相位相差180°。
			\item 由\cref{fig:有光照}、\cref{fig:无光照}可以看到，在有光照的情况下，线阵CCD可以正常工作并输出脉冲信号；在无光照的情况下，线阵CCD没有信号输出，只能检测到噪声。
				\begin{itemize}
					\item 当有光照时，CCD 的光敏元件（像素）将入射光子转化为电荷。这些电荷的累积形成了光信号，之后通过电荷转移和信号放大被读出。
					\item 在没有光照的情况下，CCD 的光敏元件不能生成有效的电荷信号，因此输出主要由暗电流和电路噪声组成。这些噪声的大小随机分布，通常表现为低幅值的随机信号，而非与光信号相关的规律性脉冲。
					\item 在有光照条件下，光信号的强度远高于噪声，信噪比较高，输出信号明显；无光照条件下，只有噪声，信噪比极低，输出信号表现为随机无规律的小幅值变化。
				\end{itemize}
		\end{enumerate}









	\subsubsection{利用线阵 CCD 测量工件直径和角位置}

		\begin{itemize}
			\item \textbf{测量工件直径：}

				\begin{enumerate}
					\item 由\cref{tbl:物体宽度测量数据}中的数据，计算测量结果并进行误差分析。
						\begin{align*}
							d_1 = \frac{1}{n}\sum_{i}^{n}d_i = 11.8883 \mathrm{mm}	\\
							\sigma_{d_1} = \sqrt{\frac{1}{n-1} \sum_{i}^{n}(d_i - d_1)^2} = 0.0271 \mathrm{mm}	\\
							d_2 = \frac{1}{n}\sum_{i}^{n}d_i = 9.9517 \mathrm{mm}	\\
							\sigma_{d_2} = \sqrt{\frac{1}{n-1} \sum_{i}^{n}(d_i - d_2)^2} = 0.0313 \mathrm{mm}	\\
							\Rightarrow d_1 = 11.89 \pm 0.08 \mathrm{mm}	\\
							\Rightarrow d_2 = 9.95 \pm 0.09 \mathrm{mm}
						\end{align*}

					\item 可以看到，测量结果的标准差较小，说明测量结果具有较好的稳定性；但是较游标卡尺的测量结果，CCD相机的测量结果明显偏小，说明可能是标定得不够精确引入了较大的误差。
				\end{enumerate}

			\item \textbf{测量工件角位置：}
			
				\begin{enumerate}
					\item 使用如下公式可计算得到角位移的大小：

						\begin{align*}
							\theta = \frac{(x_f - x_i) \times 14 \mu m}{24 cm \times \pi} \times 180°	\\
							\Rightarrow \theta_1 = 3.76°	\\
							\theta_2 = 5.13°	\\
							\theta_3 = 6.00°	
						\end{align*}

					\item 可以看到，CCD相机的测量结果较刻度盘的读数结果，有较大的偏差。一个明显的原因是，刻度盘的分度值最小是2°，读数本身就有较大误差。
				\end{enumerate}
		\end{itemize}













	\subsubsection{面阵 CCD 驱动及特性测量}

		\begin{enumerate}
			\item 由\cref{fig:SUBCK-V1}、\cref{fig:SUBCK-V2}、\cref{fig:SUBCK-V3}、\cref{fig:SUBCK-V4}可以看到，V1-V4信号的频率均为15.2kHz，周期均为65.6$\mu $s。V1、V2、V3、V4 脉冲是分时交替的信号，四者之间具有相位差90°。
			\item 由\cref{fig:H1-H2多个周期}可以看到，H1与H2信号的频率均为14.3MHz，二者相位差为180°。
			\item V1、V2、V3、V4 脉冲与垂直电荷转移相关；H1、H2 脉冲：与水平电荷转移相关。
				\begin{itemize}
					\item V1、V2、V3、V4 是四相驱动信号，每个脉冲驱动不同列中的电荷转移。通过交替的高低电平变化，逐列控制电荷的转移。
					\item H1 和 H2 是两相驱动信号，控制水平移位寄存器中的电荷移动。两相信号交替为高电平和低电平，提供周期性的电场变化，推动电荷沿水平方向转移。		
					\item 垂直与水平转移的配合：垂直转移完成后，电荷进入水平寄存器，再通过水平转移传递到输出端，完成信号采集。			
				\end{itemize}
		\end{enumerate}


















	\subsubsection{面阵 CCD 图像采集、运算和颜色处理}

		\begin{itemize}
			\item \textbf{图像采集：}

				由\cref{fig:图像明暗与灰度值的关系}，可以看到一个像素的灰度值越高，该像素点越亮；灰度值越低，该像素点越暗。

				在左边沿处，灰度值有一个明显的突变，说明这是图像的边沿位置，且灰度值变化越陡峭，说明边沿越清晰。

			\item \textbf{图像运算：}
			
				\begin{enumerate}
					\item 由\cref{fig:灰度直方图}可以看到，大部分像素集中在灰度值较低的区域（接近0），这表明图像中有大量的暗色区域；在高灰度值区域（接近255）几乎没有像素，这表明图像中几乎没有纯白色或接近白色的区域。这意味着图像的对比度较低，或者图像中的白色区域非常少；灰度值中间区域的像素数量相对较少，这意味着图像中中间灰度的过渡区域不多，图像可能缺乏细节或者在中间灰度区域有较少的像素。
					\item 由\cref{fig:图像灰度线性变换}，图像经过灰度线性变换$f(x) = -x + 255$后，图像的灰度值被反转。原本灰度值较高的像素（较亮的区域）在变换后会变暗，而灰度值较低的像素（较暗的区域）会变亮。线性变换不会改变图像中细节的相对位置和形状，但会影响细节的可见性，如果细节区域的灰度值在变换后变得不明显，那么这些细节可能会变得难以区分。
					\item 由\cref{fig:图像灰度拉伸变换}，图像经过灰度拉伸变换（$x_1 = 40 \ y_1 = 10 \Rightarrow x_2 = 150 \ y_2 = 230$）后，原始灰度值在 40 到 150 之间的像素将被映射到新的灰度值范围 10 到 230。这可以显著提高图像的对比度，使得原本灰度值相近的像素在变换后具有更大的差异，从而使得图像中的细节更加明显。图像中的特征，如边缘和纹理，也会因为对比度的增强而变得更加明显。
					\item 由\cref{fig:图像灰度阈值变换1}、\cref{fig:图像灰度阈值变换2}，图像经过灰度阈值变化。灰度阈值变换是一种二值化处理方法，它将图像的灰度值与一个或两个阈值进行比较，根据比较结果将像素值设置为不同的值，通常是0（黑色）或255（白色）。\cref{fig:图像灰度阈值变换1}中，高于阈值的灰度被设置为255，低于阈值的灰度被设置为0；\cref{fig:图像灰度阈值变换2}中，低于低阈值的灰度被设置为0；高于高阈值的灰度被设置为255，介于中间的灰度保持不变。在该过程中，原始图像中的灰度细节可能会丢失，因为所有低于阈值的像素都被设置为黑色，所有高于阈值的像素都被设置为白色；图像中的边缘和轮廓可能会变得更加明显，因为二值化处理会突出灰度值的突变区域。单阈值变换通过一个固定的灰度值将图像简化为二值图像，增强对比度但可能丢失细节，对噪声敏感，适用于背景与前景灰度差异明显的图像；而双阈值变换则通过两个阈值在保留一定灰度细节的同时调整特定灰度范围的对比度，更好地抑制噪声，适用于需要保留灰度细节或背景与前景灰度差异不大的图像。
					\item 由\cref{fig:图像灰度均衡变换1}、\cref{fig:图像灰度均衡变换直方图}，图像经过灰度均衡变换。其显著提高了图像的对比度，使得原本对比度较低的图像变得更加清晰；图像的直方图会变得更加均匀，灰度值分布从原来的集中分布变为覆盖整个灰度范围；图像中的一些特征会因为均衡变换而变得更加突出，尤其是那些在原始直方图中灰度值分布较窄的特征；图像的动态范围可能会因为均衡变换而增加，使得图像能够展示更多的亮度层次。
				\end{enumerate}


			\item \textbf{图像颜色处理：}
			
				\begin{enumerate}
					\item 如\cref{fig:图像奇偶场分开显示}，"奇偶场分开显示"指的是将视频帧中的奇数场和偶数场单独显示出来；这种交错式的显示方式可以减少运动模糊并提高视频的刷新率，以便进行更精细的调整。

					\item 如\cref{fig:图像R通道}、\cref{fig:图像G通道}、\cref{fig:图像B通道}，为分别显示该图片的不同通道的结果。可以看到，红色在红通道的灰度值比较大，绿色在绿通道的灰度值比较大，蓝色在蓝通道的灰度值比较大。
				\end{enumerate}
		\end{itemize}

					R_\odot = 2.808 \mathrm{mm}	\\

		\end{itemize}
